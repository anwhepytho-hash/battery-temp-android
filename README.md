# Battery Temp 🔋

A high-performance, ultra-lightweight Android utility designed to monitor battery temperature and voltage in real time. 

## ✨ Key Features
- **Featherlight Size:** Total size under 164 KB (App binary is ~90 KB), consuming virtually zero background resources.
- **Universal Compatibility:** Tested and verified with 10/10 stability across major OEM firmware and custom skins (Redmi, Realme, Xiaomi, Huawei, Oppo, and Samsung).
- **Zero Bloatware:** Clean, efficient code with zero ads, zero trackers, and no unnecessary permissions.
- **Open Source:** Built purely for learning, utility, and the passion for clean programming.

## 🚀 Purpose
Created as an open-source contribution and a community-driven utility for developers and users who value resource efficiency and true device autonomy.
